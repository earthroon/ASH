## 1. Purpose

ASH currently contains multiple valid lineages that evolved at different rates:

```text
Training runtime
TensorCube Attention / FFN
Loss / backward / gradient accumulation
AdamW / Local Muon / Fused Muon
BP Delta-K local observation
Bridge Delta-K
Fusion/Fission planning
Physical qualification and counterfactual evidence
Objective / trajectory evidence
Policy recommendation / review / canary / activation / health
Historical shadow, proof, and qualification lines
```

The problem is not that these lines are missing. The problem is that direct ancestry, runtime ownership, evidence dependency, policy control, and historical proof can be mistaken for one generic parent relationship.

The reconciliation therefore defines:

```text
DirectParent != RuntimeParent
RuntimeParent != EvidenceParent
EvidenceParent != ControlParent
Lineage != Authority
```

No working engine is rewritten by this patch.

## 2. Primary authority taxonomy

Every registered current patch has exactly one primary authority class:

```text
TrainingDataPlane
OptimizerDataPlane
BpDkDataPlane
BpDkPolicyControlPlane
HistoricalEvidence
```

### TrainingDataPlane

Owns current forward, loss, backward, accumulation, and finalized-gradient production.

It does not own Fusion policy selection or operator approval.

### OptimizerDataPlane

Owns actual optimizer candidate mathematics and parameter-state execution surfaces such as Local/Fused Muon.

It does not own policy recommendation or review.

### BpDkDataPlane

Owns BP Delta-K observation, freshness, Bridge evidence, candidate graph, Fusion/Fission planning, replay, POST evidence, counterfactual evidence, and objective/trajectory observation surfaces.

Delta-K remains signal/evidence. Observation authority does not itself become parameter mutation authority.

### BpDkPolicyControlPlane

Owns recommendation, explicit operator decisions, canary qualification, production policy selection, soak/health, and production-aware recalibration lineage.

It does not own gradient mutation or Muon arithmetic.

### HistoricalEvidence

Owns historical plans, proof lines, references, and superseded roadmap nodes. Historical does not mean invalid. It means no current production writer authority.
