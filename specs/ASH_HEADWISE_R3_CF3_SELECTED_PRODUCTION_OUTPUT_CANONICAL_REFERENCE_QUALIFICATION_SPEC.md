## 1. Purpose and strict scope

CF3 fills the precise missing edge:

```text
REAL Native PreparedAtlasInputs
  Q / K / V + selected position & score policy
       │
       ├─ actual selected Short32/Long64 production pipeline
       │      → qualifier-owned candidate output
       │
       └─ independently authorized matched-math reference producer
              → qualifier-owned reference output
                        ↓
              same-device numerical comparator
                        ↓
              physically completed receipt
```

The reference may not be selected by a matching filename or caller-provided SHA alone. It must be **generated by the declared producer from the same actual Q/K/V and mathematical policy** and bound to the same invocation.

CF3 does **not** change attention math, sampling, checkpoint weights, W9A routing, KV storage, future token publication, queue ownership, or the default production policy.

## 4. CanonicalGqa matched-reference contract

For policy `CanonicalGqa`:

```text
score(q,k) = dot(q,k) / sqrt(head_dim)
context    = sum(softmax(masked_scores) * v)
```

The reference must use the same:

```text
batch, q_heads, kv_heads, query_heads_per_kv, head_dim
actual Q/K/V buffer identities and storage layout
query absolute-position base and KV position base
position epoch and causal-mode identity
per-query readable KV set
GQA head mapping
nonempty-row and softmax finite semantics
```

An independent Burn GQA reference is admissible only if it implements the **same causal mask and layout** as the actually selected Headwise route. A bare unmasked `grouped_query_attention()` call is not a valid reference when Headwise is causal.

The existing reference WGSL can be used only within its proven geometry/math scope; its current source does **not** prove all cases above. Where it does not match, the status is `HOLD_HEADWISE_R3_CF3_CANONICAL_REFERENCE_UNSUPPORTED`, not automatic equivalence.

## 5. LegacyTextDensityAdjusted reference contract

For `LegacyTextDensityAdjusted`, reference math MUST include the exact TextDensity-related factors and their applicable clamp/maximum operations, along with the same score policy ID.

Required identity:

```text
text_density_uniform digest
packed path ID and lane density policy
cairo/coda/curvature/zero-copy factor identity
ordered score operations or explicitly measured numerical tolerance
selected short/long shader source digest
```

The existing reference-measurement WGSL uses `dot * params.scale` without these multipliers. Therefore:

```text
LegacyTextDensityAdjusted
  + bare headwise_reference_attention_measurement.wgsl
  -> NOT_MATCHED_REFERENCE
```

Build or qualify a separate independent, *policy-matched* reference producer. Do not copy the selected production WGSL verbatim and call it an independent oracle without a separate source/math qualification.

A parity failure caused by comparing different policies must be classified `REFERENCE_POLICY_MISMATCH`, **not** evidence that the Headwise selected pipeline is wrong.
