# 2. Root cause

C10 treated `DecoderWeightAtlasWavePlan::role_registry_digest` as a layer-invariant schema identity.

That assumption is false.

C4 builds `role_registry_digest` from entries containing:

```text
registry_ordinal
commit_ordinal
role
tensor_key
canonical_role
expected_shape
```

The `tensor_key` is produced by:

```rust
role.tensor_key(target_layer)
```

and therefore contains the target layer:

```text
model.layers.4....
model.layers.5....
model.layers.6....
...
```

Consequently:

```text
Layer4 role_registry_digest != Layer5 role_registry_digest
```

is expected even when the nine-role decoder schema is perfectly unchanged.

C10 compared these target-bound instance identities across all rebinds and incorrectly classified valid layer variation as structural drift.

# 3. Identity classification

After C10-D1 two distinct identities are explicit.

## 3.1 Target-bound registry instance identity

```text
role_registry_digest
```

Contains:

```text
registry ordinal
commit ordinal
role
target-layer tensor key
canonical role
expected shape
```

Semantics:

```text
which exact target-layer tensor registry instance did this C4 plan bind?
```

This identity is expected to vary across target layers.

It remains valuable provenance and is not removed.

## 3.2 Layer-invariant role schema identity

```text
role_schema_digest
```

Contains:

```text
registry ordinal
commit ordinal
role
canonical role
expected shape
```

It intentionally excludes:

```text
target-layer tensor key
checkpoint span
tensor identity digest
target layer number
```

Semantics:

```text
is the decoder weight role schema/order/shape contract still the same?
```

This identity must remain stable across decoder layers for the same architecture/configuration.



No target-layer-specific field participates.

# 15. Architecture seal

> Decoder role identity has two layers and they must not be conflated. The target-bound registry digest identifies the exact `model.layers.N.*` tensor set selected for one rebind and is therefore expected to change as N changes. The role-schema digest identifies the layer-independent decoder weight contract, including canonical role, registry/commit ordering, and expected shape, and is therefore the correct long-horizon drift authority. C10-D1 preserves both identities, compares only the schema identity across layers, keeps all cardinality/work/provenance checks fail-closed, and changes no numerical execution or runtime weight transport behavior.
